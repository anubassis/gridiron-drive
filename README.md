# Gridiron Drive

A 3D mobile-friendly American football game you can play in the browser.

**Play:** https://anubassis.github.io/gridiron-drive/

## How to play

You play offense as the Bay City Hawks against the Redwood Wolves.

- **Phone:** tap to take the snap as quarterback, hold to aim, and release to throw to receivers running routes. After a catch, run the ball past tacklers.
- **Computer:** use WASD or the arrow keys, and click the mouse to throw.

## Run it locally

Open `index.html` in a browser. The game is self-contained and works offline.
